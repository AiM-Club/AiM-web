## 🎯 프로젝트 소개

**Aim**은 유저가 설정한 목표를 바탕으로 AI가 맞춤 루트를 설계하여, 유저가 다양한 분야의 목표를 꾸준히 실천하고 달성할 수 있도록 돕는 챌린저스 플랫폼입니다.  
프론트엔드와 백엔드를 나누어 **React와 Spring 기반**으로 개발되었습니다.

**게이미페이션**을 통해 타 서비스와 다르게 기록+목표 달성 과정을 게임처럼 경험한다는 차별점을 통해 몰입감을 높였습니다.
